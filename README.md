## 🌴 What is this?

**Monkey Clicker** is a tiny, adorable clicker game where you tap a very cute monkey to collect bananas.
More bananas means more upgrades, more upgrades means more monkeys, and more monkeys means... even *more* bananas! 🍌

```
   .-"-.        .-"-.        .-"-.
  (o\_/o)      (o\_/o)      (o\_/o)
  /'---'\      /'---'\      /'---'\
   `~~~`        `~~~`        `~~~`
  you  →   your friends   →   a whole jungle!
```

---

## 🎮 How to play

1. 🐒 **Click the monkey** to earn bananas
2. 🍌 **Spend bananas** in the shop on upgrades
3. 🌿 **Hire helpers** that click for you while you nap
4. 👑 **Climb the leaderboard** and become the Banana King

---

## ✨ Features

- 🍌 Satisfying, squishy click animations
- 🐵 Collectible monkeys with silly names
- 🛒 A banana shop full of upgrades
- 💤 Idle bananas: monkeys keep working while you're away
- 🏆 Achievements to unlock
- 🎶 Cheerful jungle sounds *(optional, mute anytime)*

---

## 🚀 Getting started

```bash
# 1. Grab the code
git clone https://github.com/your-username/monkey-clicker.git

# 2. Go into the jungle
cd monkey-clicker

# 3. Install the dependencies
npm install

# 4. Start swinging!
npm run dev
```

Then open **http://localhost:3000** and start clicking! 🎉
